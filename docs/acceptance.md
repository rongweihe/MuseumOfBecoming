# 来时路 MVP 验收记录

验收日期：2026-10-07（Asia/Shanghai）。运行环境：Node.js 22、Chrome、React + TypeScript + Vite。所有验收记录与截图中的个人馆藏均为测试输入，不是 remy 的真实故事。

## 自动验收

- `npm test`：12 项数据与事务测试。
- `npm run test:e2e`：生产构建及 10 项浏览器流程测试。
- TypeScript 严格检查及 Vite 生产构建。

测试覆盖：

| 要求               | 验收方法                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------ |
| 演示与个人隔离     | 首次显示六件虚构演示；建馆后计数为零；收藏后在两个模式间切换，个人数据保持不变             |
| 三字段收藏与持久化 | 填写标题、日期、结果，成功揭幕；刷新详情仍能读回结果和信笺                                 |
| 揭幕时机           | 新建事务成功后出现；编辑不出现；模拟配额失败时无揭幕，表单与旧馆藏保留                     |
| 精选限制           | 满三件后出现明确替换选择；替换维持三件；删除同时移除精选引用                               |
| 草稿恢复           | 离开保存草稿、刷新、继续填写；模式切换与浏览器返回均有离开确认                             |
| 日期精度           | 月记录保持 YYYY-MM，显示年月；闰年、非法日历日期校验；切换到日精度不推断日期               |
| 搜索与重访         | 主题和正文搜索；从详情返回保留筛选、搜索、滚动与键盘触发焦点                               |
| 备份恢复           | 实际下载 JSON，在空的同源隔离浏览器中导入，馆主、故事、精选、日期精度一致                  |
| 导入失败保护       | 拒绝非法 JSON、未来版本、重复 ID、无效引用、危险链接、超额数据；模拟写入失败不覆盖当前记录 |
| 原子事务           | 模拟第二项写入结构化克隆失败，回滚已排队写入，草稿和旧馆藏均保留                           |
| 存储不可用         | 模拟 IndexedDB 禁用，明确显示临时模式，仍能收藏并导出；不声称永久保存                      |
| 子路径与直达       | 用普通静态服务在 /Museum_of_Becoming/ 运行 dist；资源、hash 详情直达与刷新成功             |
| 网络隐私           | 生产浏览器测试仅观察到同源静态资源请求；搜索不产生外发网络请求                             |
| 键盘               | Enter 打开展品、标题聚焦、返回恢复触发卡片焦点；弹窗 Tab 循环与 Escape 关闭并恢复焦点      |
| 手机与减少动态     | 360×800 完成创建、预览、揭幕、详情；无水平溢出；减少动态时揭幕静态显示                     |
| 纯文本             | 带 script 字样的标题显示为文本，不生成脚本节点                                             |

## 视觉验收

人工查看以下四张截图，核查物件形体、铭牌可读性、文字溢出、页宽和按钮。

1. [1440px 桌面展厅](screenshots/01-desktop-museum.png)：暖白空间、侧光、三座高低展台，精选三列，六件完整馆藏。
2. [桌面详情](screenshots/02-desktop-exhibit.png)：深色物件展示框与暖白故事，五段经历与独立信笺。
3. [360px 手机展厅](screenshots/03-mobile-museum.png)：折叠菜单、单列卡片，主题可换行，无水平溢出。
4. [新建揭幕](screenshots/04-new-exhibit-unveiling.png)：柔光、统一物件、标题与意义，在明确保存之后呈现。

五款物件使用统一的 Artifact 组件，首页、预览、详情和揭幕都由同一记录的物件与配色参数渲染。正文使用深色文字；交互焦点明确，减少动态模式禁用转动和揭幕移动。首屏无全屏强制动画、音效或积分。

## 交付边界

- 已准备 GitHub Pages 手动工作流，未发布、未推送、未绑定未知远程仓库。
- 第一版所有 P0 已实现；后续纪念卡、上传、跨设备同步、账号与在线 AI 未实现。
- 数据只存在当前浏览器；静态页面本身可公开访问。导出备份是浏览器以外保留记录的方式。
- 当前不处理两个标签页同时编辑同一展品的自动合并；日常使用建议在一个标签页编辑，完成后导出备份。
- 本次验收使用 Chrome；未对 Safari、Firefox 和屏幕阅读器进行实机全矩阵验证。提供了语义 HTML、原生 dialog、表单标签、状态提示与键盘支持，但不将它描述为完整无障碍认证。
